# 用户部署硬件和费用

核对日期：2026-10-26。下面区分官方报价与预算假设，费用不含人工运维、税费及域名。地区、账号、计费方式和优惠会变化，购买时以控制台确认为准。

## 硬件方案

| 场景 | CPU 和内存 | 磁盘 | GPU | 适用范围 |
|---|---|---|---|---|
| 本机开发 | 建议 4 核、8 GB 可用内存 | 10 GB 以上空闲 | 不需要 | Docker/浏览器/编辑器；实际占用取决于其他进程 |
| 单机演示 | 2 vCPU、4 GiB | 系统盘 40 GiB | 不需要 | Django、SQLite、远程模型 API，不能宣称高可用 |
| 三节点课程集群 | 每节点 2 vCPU、4 GiB，共 6 vCPU、12 GiB | 每节点 40 GiB，共 120 GiB | 不需要 | 1 控制平面+2工作节点；应用单副本绑定数据节点 |
| 后续多人试用 | 应用节点至少 4 vCPU、8 GiB 起评估 | 独立数据库/备份存储 | API 模式不需要 | 压测后定容，不能仅凭规格保证并发 |

不在三个 ECS 节点本地部署大模型。若未来改为自托管，需要另行按模型权重、量化精度、上下文和并发测算显存，不能照搬上述 CPU 预算。

## ECS 预算示例

采用假设综合单价 0.30 元/节点小时（仅为课堂预算参数，不是阿里云当前报价；需确认是否覆盖系统盘）。按 30 天、每天 24 小时运行：
单机=1×0.30×720=216 元/月；三节点=3×0.30×720=648 元/月。
按演示总共开机 20 小时：单机=6 元，三节点=18 元。停机期间仍需另计保留云盘等资源。

另外预留公网流量、镜像仓库超额、备份和日志等费用；示例按流量 10 元/月、备份 10 元/月、仓库 0 元/月预算（仓库 0 元仅假设账户未超出可用免费额度，不是长期免费承诺）。每项应替换为控制台实际值。

普通停机通常不停止全部计费；节省停机模式也主要停止计算等资源费用，云盘等仍可能收费。释放实例前备份，尤其本地 PV 数据不会因 Retain 自动获得云备份。

## 模型 API 费用

阿里云百炼 qwen-plus 华北2（北京）、非思考模式、单次输入<=128K 的官方页面原价为：输入 0.8 元/百万 tokens，输出 2 元/百万 tokens。此条件不适用于思考模式输出或其他地区/档位。

假设 50 名学生，每人每天 10 次讲解，每次输入 1500 tokens、输出 500 tokens，30 天共 15000 次：
输入=2250万 tokens，费用=22.5×0.8=18 元；
输出=750万 tokens，费用=7.5×2=15 元；
合计约33元/月。当前代码输出上限800 tokens，上述500是预算平均值，实际以 usage 和账单计量。缓存收益和免费额度未计入。

同一假设下每次费用约0.0022元；20次人工抽检约0.044元，仅为 token 数假设下的估算，不含其他资源。mock 模式没有模型 API 费，但服务器仍收费。

## 总预算

按上述假设：单机持续运行约216+33+10+10=269元/月；三节点约648+33+10+10=701元/月。不是采购报价，也不是本项目并发性能承诺。若复用已付费课程集群，计算资源增量可能较小，但原集群成本不能算零。
